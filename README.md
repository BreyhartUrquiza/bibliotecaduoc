# 📚 Proyecto Biblioteca - Spring Boot

Proyecto académico desarrollado en Spring Boot que implementa una API REST para la gestión de libros y solicitudes de préstamo.

---

## 🚀 Tecnologías utilizadas

- Java 17
- Maven
- Postman
- Arquitectura en capas (Model, Repository, Service, Controller)

---

## 📌 Funcionalidades

- Listar libros
- Buscar libro por ID
- Buscar libro por ISBN
- Crear libro
- Actualizar libro
- Eliminar libro
- Crear solicitud de préstamo
- Listar solicitudes de préstamo

---

## 🛠️ Cómo ejecutar el proyecto

1. Clonar el repositorio
2. Abrir en VSCode
3. Ejecutar la clase `BibliotecaduocApplication`
4. Probar los endpoints en Postman
